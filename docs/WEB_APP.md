# Web app (iPhone, Android, PC)

**Address:** `https://YOUR-SITE.vercel.app/app/`. The status page also has an **Open web app** button.

It uses the same accounts, channels, plans and admin page as the Android app, and both apps can talk to each other in the same channel.

## Install it like an app
- **iPhone (Safari):** open the address → **Share** → **Add to Home Screen**. It then opens full-screen with the logo icon.
- **Android (Chrome):** open the address → **⋮** menu → **Install app** / **Add to Home screen**.
- **PC:** open in Chrome or Edge, and click the install icon in the address bar if you want a desktop window.

## Limits of a browser app (be clear with clients)
- **Keep it open on screen.** iPhone and Android pause browser audio and GPS when the screen locks or you switch apps. The app keeps the screen awake while you're in a channel.
- No volume-key push-to-talk. Browsers can't read the volume buttons.
- No lock-screen push-to-talk on iPhone. That needs the native iPhone app (Apple Push to Talk) and an Apple Developer account.
- On iPhone, the first tap after opening unlocks audio (an Apple rule). After that, incoming voice plays normally.

For guards and staff on duty, the **Android app** is still the best choice (screen-off listening, volume-key PTT, NFC). The web app is ideal for iPhone users, supervisors and control-room PCs.
